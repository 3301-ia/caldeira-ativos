# Caldeira Gourmet · ativos visuais

Repositório dedicado às imagens do projeto Caldeira Gourmet (Minas Tênis Clube II).
Serve para anexar e compartilhar arquivos visuais por link direto, sem depender de envio por aplicativo.

## Estrutura

- `logos/` — marcas oficiais: Caldeira em disco navy com panela dourada, assinatura Caldeira, selo MTC 90 anos.
- `logos/legado/` — logos antigas, mantidas apenas como histórico.
- `icones/` — folha de ícones de categoria (açaí, sobremesas, porções, combos).
- `capa/` — capa oficial navy com moldura dourada e as duas assinaturas.
- `referencias/` — páginas de referência do kit visual.
- `capturas/` — capturas de tela do sistema.

## Uso direto

Link bruto de cada arquivo:
`https://raw.githubusercontent.com/3301-ia/caldeira-ativos/main/<pasta>/<arquivo>`

Exemplos:
- https://raw.githubusercontent.com/3301-ia/caldeira-ativos/main/logos/caldeira_disco.png
- https://raw.githubusercontent.com/3301-ia/caldeira-ativos/main/logos/mtc_90anos_crop.png
- https://raw.githubusercontent.com/3301-ia/caldeira-ativos/main/capa/capa_original.jpg

## Regra de uso

Documentos, fichas e telas do sistema usam exclusivamente este kit. As logos antigas do legado não entram em peça nova.
