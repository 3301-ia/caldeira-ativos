## Regras do código

1. O código nunca muda. Preço muda, nome muda, código não.
2. Item novo entra no fim da subfamília, com o próximo sequencial.
3. Item descontinuado não é apagado: fica inativo e o código não é reaproveitado.
4. O prefixo CG permite juntar bases de projetos diferentes sem colisão. A plataforma de personagens usará outro.
5. Nada de código por ordem alfabética. Código é posição, não nome.
